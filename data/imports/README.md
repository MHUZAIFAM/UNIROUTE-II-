# data/imports

Working files for the university **domain** and **program** datasets.
Everything here is generated by, or feeds into, a script in `backend/`.

## Work here now

| File | What it is |
|---|---|
| **domains_to_fix_remaining.xlsx** | **The active worklist.** 1,622 universities still needing a domain. Amber rows are the QS top-1000 (59 left) — do those; the rest are ranked 1001+ or unranked and are low value. Fill the `Correct domain` column. |
| **extractable_queue.csv** | 294 universities whose program catalogue is reachable, rank-ordered. The input for program extraction, the next phase. |

When a batch of domains is filled in, verify before trusting:

```bash
python backend/verifyDomainBatch.py <batch.tsv> --apply
```

## Needs a human decision

| File | What it is |
|---|---|
| **domain_matches_needs_review.csv** | 65 fuzzy domain matches that were **not** applied. Roughly half point at the wrong institution (MGIMO matched ITMO, Wrocław matched AGH, Tokai matched Tokiwa), so each needs an eye before use. |

## Evidence — keep, don't edit

| File | What it is |
|---|---|
| **domains_verified.csv** | Every domain accepted so far, with what confirmed it and when. The provenance trail. |
| **domain_check_dns2.csv** | Full DNS state of all 10,876 universities. The basis for the "1,820 need fixing" figure. |
| **catalogue_survey_v2.csv** | Catalogue reachability for the top 1,000, after the domain backfill. Records which universities block automated access and why. |
| **university_programs_web_batch_01.xlsx** | 115 programs (MIT, Caltech, Cambridge) sourced from official listings. |

## archive/

Superseded, kept only so results stay reproducible. Nothing here needs attention.

- `domains_to_fix.csv` / `.xlsx` — the original 1,820-row worklist, including the 198 rows filled in by hand. Replaced by `domains_to_fix_remaining.xlsx`.
- `catalogue_survey_top1000.csv` — first survey, run **before** the domain backfill (226 extractable). Replaced by `catalogue_survey_v2.csv` (294).
- `catalogue_survey_test.csv` — 40-row trial run.
- `domain_matches.csv` — full duplicate-matching report. The actionable part is `domain_matches_needs_review.csv`.
- `domain_batch_verified.csv` — verification output for the 202-row batch; results already applied and logged in `domains_verified.csv`.
